INSTALLATION

简单一键，立即安装 AMT

提供 Homebrew Cask、一键终端脚本以及直接 DMG 下载镜像。

在 macOS 终端中运行以下命令，即可通过 Homebrew Cask 自动安装并管理后续升级：

brew tap wuyunfeng8/antigravity-manager https://github.com/wuyunfeng8/Antigravity-Manager && brew install --cask antigravity-tools

无需 Homebrew，通过官方一键 Shell 脚本直接下载并安装至 /Applications：

curl -fsSL https://raw.githubusercontent.com/wuyunfeng8/Antigravity-Manager/main/install.sh | bash

FREQUENTLY ASKED QUESTIONS

常见疑问解答

AMT 是 API 代理或中转反代吗？我能用它接入 NextChat / OneAPI 吗？ +
不是。 AMT 专为 Google Antigravity 原生桌面客户端管理设计，负责监控真实配额、推荐接力与设备身份切换。项目中明确去除了所有 HTTP 网关、API Key 分发、Headless 模式及第三方兼容端点，不提供 API 反代功能。
一键接力切换账号后，我的 IDE 插件、工作区历史与代码会丢吗？ +
完全不会。 AMT 的接力机制是精准替换 Antigravity 原生客户端在系统凭据库（macOS Keychain）或兼容 SQLite 中的授权登录状态，并在重启时保留所有打开的工作区、文件与编辑器设置，换号后立刻无缝继续写代码。
设备身份隔离能保证 100% 不会被封号吗？ +
不作此类绝对保证。 任何工具都无法规避平台的整体风控模型。AMT 提供的是客户端层面的设备身份隔离（如 machineId, macMachineId, devDeviceId），主要目的是降低多个账号在同一设备上长期共用相同硬指纹带来的直接关联风险，并支持随时还原原始环境基线。
我的账号 Token 会被上传到远程服务器吗？ +
绝对不会。 AMT 没有任何后端中心化服务器或遥测后台。所有账号数据仅存放在你本地 Mac 的 ~/.antigravity_tools 目录中，并使用 Unix 0600 安全权限防护，刷新配额直接与 Google 官方端点通信。你可以随时在源码中审查网络请求模块。
