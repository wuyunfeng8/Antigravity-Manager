WHY AMT

为什么重度 Antigravity 开发者都在用 AMT？

我们深知写代码正处在心流巅峰时突然弹出 429 报错的痛苦。看看传统繁琐方式与 AMT 的鲜明对比。

从「繁琐登出重登」到「一键静默接力」

传统痛苦流程: 额度耗尽 → 退出主程序 → 浏览器发起 OAuth → 网页授权登录 → 重新绑定项目配置。每次打断 3~5 分钟编码心流。
AMT 丝滑体验: 后台实时监控余量，额度低时推荐最佳备用号。点击一键接力，1秒写入系统 Keychain 并热重启，心流不中断。
接力效率提升 300%+

从「瞎猜模型配额」到「权威真实口径」

普通工具弊端: 依靠模型名或变体盲目猜测账号等级，搞不清 5 小时滑动窗口与周配额的区别，经常在关键时刻误报。
AMT 权威直连: 直接聚合 Google 官方 loadCodeAssist 返回的真实配额桶，精准分离 Claude / Pro / Flash，严谨展示恢复倒计时。
配额准确率 100% 官方一致

从「共用指纹关联」到「独立设备身份」

多账号潜在风险: 多账号长期在同一台电脑切换，客户端 machineId、macMachineId 完全相同，易被平台风控判定关联。
AMT 身份隔离: 为每个账号绑定独立设备身份指纹与原始基线快照。切号时同步应用，有效降低多账号关联风险。
环境关联度 显著隔离

INSTALLATION

简单一键，立即安装 AMT

提供 Homebrew、一键脚本与 DMG 原生安装包多种途径。

打开 macOS 终端，执行以下两条命令即可通过官方 Tap 自动安装并纳入 Cask 管理：
brew tap wuyunfeng8/antigravity-manager https://github.com/wuyunfeng8/Antigravity-Manager && brew install --cask antigravity-tools
适合没有安装 Homebrew 的用户，一键下载解压并自动安装到 /Applications：
curl -fsSL https://raw.githubusercontent.com/wuyunfeng8/Antigravity-Manager/main/install.sh | bash
