立即安装 AMT

支持 Homebrew Cask、一键终端脚本和 DMG 直接下载。

打开终端，执行以下命令通过 Homebrew Cask 安装：

brew tap wuyunfeng8/antigravity-manager https://github.com/wuyunfeng8/Antigravity-Manager && brew install --cask antigravity-tools

适合没有 Homebrew 的用户，一键下载并安装至 /Applications：

curl -fsSL https://raw.githubusercontent.com/wuyunfeng8/Antigravity-Manager/main/install.sh | bash

FAQ

常见问题

AMT 是 API 代理或中转网关吗？ +
不是。AMT 专为 Google Antigravity 原生桌面客户端管理设计，负责监控真实配额、推荐接力与设备身份切换。项目中明确去除了所有 HTTP 网关、API Key 分发、Headless 模式及第三方兼容端点。
切换账号后，工作区和代码会丢失吗？ +
完全不会。AMT 的接力机制精准替换系统凭据库中的登录状态，重启时保留所有打开的工作区、文件与设置，换号后立刻无缝继续。
设备身份隔离能保证 100% 不被封号吗？ +
不作此类绝对保证。设备指纹隔离的目的是降低多账号在同一设备上长期共用相同硬指纹带来的直接关联风险，并支持随时还原原始环境基线。
我的账号 Token 会被上传到远程服务器吗？ +
绝对不会。AMT 没有任何后端中心化服务器或遥测后台。所有数据仅存放在本地 ~/.antigravity_tools 目录，配额刷新直接与 Google 官方端点通信。源码随时可审查。
